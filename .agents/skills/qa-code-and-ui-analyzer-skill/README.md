# qa-code-and-ui-analyzer-skill

Codebase and UI feature intelligence extractor for OMK POS and modern Vue/Nuxt 4 applications.

## Usage

```bash
# Analyze a feature by ID
python3 scripts/feature_analyzer.py --feature f02 --output feature-analysis.json

# Run via agent command
/qa-analyze f02-pos-cashier
```
